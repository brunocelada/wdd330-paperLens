# **PaperLens**

### Simplifying Scientific Literature

## Student: **Bruno Celada**

## External APIs: [**OpenAlex**](https://openalex.org/) + [**Crossref**](https://www.crossref.org/)

## Description

PaperLens will be a responsive web application that helps students find and understand scholarly papers without requiring them to navigate the full, large and complex research metadata platform. The problem to be addressed is that scholarly systems always expose a very large amount of information, but a student who is simply trying to identify useful papers for an assignment often needs only a concise subset of that information.
The application will use [OpenAlex](https://openalex.org/) as its primary scholarly data source. Its API supports search, filtering, sorting, pagination and field selection, which makes it suitable for building focused student-oriented interface. PaperLens will turn a query into a manageable results page with title, authors, year, topic, DOI, and relevant open-access information. A detailed view will expose additional metadata only then useful. [Crossref](https://www.crossref.org/) will be used as a second external API for DOI-based bibliographic metadata and citation-oriented information.
This project is motivated by my academic background in chemistry and my experience using scientific literature. The goal is to create a student friendly tool that makes the most relevant metadata easier to scan, compare, save and cite.
